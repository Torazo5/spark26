# Porch

Prototype community board for 5C students and the staff and faculty living in the new residential area. Three kinds of posts: **Projects** (ongoing work in the area), **Classes** (recurring teaching), and **Events** (one-offs).

```bash
npm install
npm run dev
```

Data is seeded from `src/seed.js` and saved to the browser's localStorage. Use "Reset demo data" in the footer to start over. Rename the app and place in `src/config.js`.

Deploy: import the repo on Vercel (framework preset: Vite). No config needed.
